Compiling
  • An idle game about rendering masks. Each one compiles on a timer, pays out, and the next is pulled at random.
    •  
  • Masks come from a database weighted by rarity, so what turns up next varies.
Upgrades
  • Earnings buy CPU and GPU upgrades to compile faster, or Enrichment to raise what each mask is worth.
    •  
  • Purchases are checked against current funds before anything is applied.
    •  
  • Built in two days for Global Game Jam 26, with a team of three.
