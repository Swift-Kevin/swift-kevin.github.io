About
  • Remake of John Conway's Game of Life, a cellular automata simulation. Using wxWidgets for rendering.
    •  
  • Features file I/O for saving game boards, options for cell state colour, customisable grid size, and more.
    •  
  • Completed in roughly 3 weeks during my first Project and Portfolio class at Full Sail University.
Editing the Board
  • Click on cells to toggle their state either alive or dead.
    •  
  • Cells use the Conway's Game of Life cellular automata rules.
Seeding
  • Option to randomize cell states based on either a seed or the current time since epoch.
    •  
  • Useful for watching how different densities settle down, since most random fills stabilise or die out.
Grid and Window
  • Grid dimensions are adjustable by width and height, so the same rules can run on a small board or a large one.
    •  
  • Cells dynamically resize to match the window if adjusted.
View Options
  • Display settings are exposed through a menu rather than hard-coded.
    •  
  • Options for torodial and fixed wrapping can allow gliders to work.
    •  
  • Cell colours and grid appearance are customisable, which is what makes different rule sets readable at a glance.
